# EdgeStack 用户可视化工作台实施记录

日期：2026-11-15。本文为公开源码发布说明，记录功能验收范围和实现边界；实际设备配置、对话内容与联调证据保留在部署者私有目录。

## 已交付结构

- 普通用户默认进入独立导航和浅色 SVG 设备空间；管理员保留原生首页与完整侧栏，通过显式入口预览用户视图。
- 用户场景采用独立 JavaScript、SVG 和 CSS，复用现有认证与路由。相对设计中的 React/TypeScript 组件方案，这是首版实现调整；原生管理 bundle 保持固定基线。
- Go 业务模块提供任务登记、来源凭据、事件接收、查询、总结和受控模型更换；数据库独立保存于 `/data/edgestack/business.db`。
- Worker 适配器只读业务 JSONL，并用独立持久队列上报；不挂载 Docker socket，不持有管理员或云端密钥。
- 任务登记、实际容器运行、模型加载和业务互动分别表达；数据位置只显示授权登记及实际挂载核验结果。

## 实际验收范围

| 项目 | 结果与范围 |
| --- | --- |
| 真实语音 | 在一台 RK3588 的独立测试任务中完成 ASR、TTS、用户主动录音、文字回显与播放回执 |
| 对话含义 | 测试入口采用回声回复，验证接入链路，不包含完整对话大模型 |
| 事件可靠性 | 独立适配器断网后恢复上报，原事件 ID 保留，相同事件重放被去重 |
| 云端总结 | 完成真实事件的一般总结、有问题回答和引用展开；密钥只由 Server 读取 |
| 模型更换 | 同一家族 ASR 模型的 4 秒、2 秒编码窗口包更换与恢复，取得真实加载及推理回执；不是不同对话模型的切换 |
| 数据与配置 | 核对端口、数据卷和无关配置保持预期；原有语音、Agent 和验收实例的保护字段一致 |
| 界面 | 覆盖单/多节点、筛选、窄屏、减少动态效果、历史补传、引用及管理员预览返回 |
| 离线演示 | 数据与操作明确标注模拟，不连接真实设备、不调用云端 |

设备场景的多节点布局使用明确的模拟数据验证；实际硬件验收为一台设备。24 节点隔离浏览器采样达到目标性能，不作为多板实机结论。

## 协议与权限

正式事件使用 `voice.user_utterance`、`voice.assistant_reply`、`voice.playback_state` 和 `camera.observation`。普通启动日志不替代交互内容。ASGI 钩子区分最终转写、回复生成、合成完成和客户端实际播放。

来源凭据固定关联设备、任务、来源与上报能力；浏览器沿用原登录和设备授权。模型选择来自已发布且兼容的不可变包，确认前重新检查任务版本和权限。挂载查询沿用原 Edge 反向隧道，只返回经授权且用途登记的核验结果。

当前 JSONL 适配器不能证明整个历史区间采集完整，因此保守报告覆盖不完整。来源未接入、缺少记录与覆盖缺口分别显示。

## 公开发布与检查

本次发布包含生产源码、测试、部署模板、构建入口和演示源码。发布副本中演示及拒绝测试的实际局域网地址已替换为文档保留地址，不改变生产行为；原设备配置与私有分支历史不进入新提交。

检查覆盖 Go 业务及 HTTP 接线、Worker 持久队列与 TLS、用户界面及离线演示。当前发布副本的测试记录由发布者保留，复现命令见根目录 README 和各模块文档。

## 已知边界与后续工作

- 真实摄像头程序尚未接入，当前提供事件协议及明确演示。
- 完整语音对话模型、更多模型家族、多板硬件分别接入验收。
- 当前总结证据时间采用 UTC，浏览器时间线采用本地时间；尚未传入用户时区，生成的“上午/下午”可能与本地时间线不一致，具体时间以引用为准。时区上下文列入后台补充计划。
- 已有未登记容器不会根据名字推测业务用途。事件保留策略只作用于新增模块。
- 现有管理员业务登记主要依靠专用接口和私有启动配置。安全编辑、配置持久化、业务管理页面、网页更新 Key 和业务库备份扩展见[管理员后台补充计划](../EdgeStack管理员后台补充计划.md)，尚未随本次源码发布实现。

构建、配置、发布前一致备份和回退见[Server 文档](../deploy/server/README.business.md)。前后端回退不会自动撤销设备上的模型变更，须按操作记录重新预览、确认并核对加载回执。
