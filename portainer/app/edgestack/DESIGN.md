# EdgeStack 用户工作台

登录后的四个业务页面共用暖纸色背景、森林绿操作色和本地 Tabler 图标。暖色表面、深色正文和单一主操作的层级取自 VoltAgent 收录的 Oura 设计分析。具体色值和字号按中文设备工作台调整。[Oura 参考文档](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/oura/DESIGN.md)

| 用途 | 工作台色值 |
| --- | --- |
| 页面底色与操作面板 | `#f7f6ef`、`#fffefa` |
| 标题与辅助文字 | `#23392e`、`#566557` |
| 主操作与已选筛选项 | `#31513d` |
| 分隔线与轻量底色 | `#d8ddd1`、`#e9eee0` |

页面以标题、授权设备概览、当前操作区的顺序排列。设备数、管理在线数和业务任务数分别计数。时间取自最近一次成功同步，过期状态用文字说明。设备详情中的管理连接、业务运行和模型回执各有独立含义。

桌面将筛选、搜索和视图切换放在同一行。窄屏将搜索与视图切换放到第二行，首次进入默认显示设备列表。手机主要控件保留至少 44 CSS 像素的点击高度。中文输入法组词期间保留搜索框。查询没有结果时，用户可以直接清除筛选。

单台授权设备在工位旁展示连接记录和详情入口。多台设备保留各自的工位坐标，筛选只改变可见性。图标按登记业务类别选择，管理连接和任务状态始终同时提供文字。
